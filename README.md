# Xiaoyu Li — Research Homepage

Static personal research homepage hosted on GitHub Pages at [larry4nn.github.io](https://larry4nn.github.io/).

## Structure

- `index.html` — Main editorial academic homepage (Highlights, Research Agenda, Publications & Technical Reports, Background)
- `assets/css/style.css` — Light/dark editorial stylesheet with responsive & print support
- `assets/js/main.js` — Theme persistence, publication topic filters, inline BibTeX drawers, and clipboard helpers
- `.nojekyll` — Disables Jekyll preprocessing so GitHub Pages serves static assets directly

## Local Preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
